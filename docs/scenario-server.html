场景与服务端常量

场景（scenario）是手势脚本；服务端是 core/lvgl_ai/web/ 的 HTTP/UI 适配层。

本页是索引指针：不复制 schema 版本、步骤字段、字段默认值、路由表、常量值或行号。每个主题只指向真源文件与符号，链接目标才是真源。路径均相对仓库根。

1. 场景格式

  • schema、顶层字段、步骤类型与默认值： core/lvgl_ai/scenario.py · SCENARIO_SCHEMA, STEP_TYPES, _STEP_FIELDS, load_scenario, normalize_steps。 模块 docstring 同时是格式示例与各步骤字段说明的真源。
  • 步骤执行与展开： core/lvgl_ai/scenario.py · play_scenario, _play_step, _interpolate。
  • 校验错误与 CLI 映射： core/lvgl_ai/control/errors.py · ScenarioError； core/cli.py · main。
  • 与 Runtime.input 事件列表的关系： core/lvgl_ai/control/runtime.py · Runtime.input； 设计说明见 .scratch/ai-tools/SPEC.md「输入」。

2. 网页服务端

  • HTTP 路由、方法、请求校验与错误映射： core/lvgl_ai/web/webapp.py · _WebHandler._route, WebApp。 路由表以这里为准，本页不转抄。
  • 服务端常量与上限： core/lvgl_ai/web/webapp.py 模块级常量。值以代码为准，本页不转抄。
  • live 时间语义与 ticker： core/lvgl_ai/web/live_session.py · TICK_PROFILE, LiveSession._default_runtime, LiveSession._start_ticker_locked。
  • raw 预览帧格式与页面心跳： core/lvgl_ai/web/wire.py · header_fields, page_config, PAGE_HEARTBEAT_INTERVAL_MS； 帧编码与 hub 见 core/lvgl_ai/web/transport.py · encode_frame, LiveFrameHub。
  • 启动参数与默认值： core/web.py · build_parser, main；用法见 core/README.md。
  • Windows 下子进程无控制台窗口： core/lvgl_ai/control/engine_link.py · spawn_engine； 构建侧子进程见 core/lvgl_ai/control/build.py · run_capture。

3. 相关文件

  • core/lvgl_ai/scenario.py — 场景 schema、校验、play_scenario
  • core/lvgl_ai/control/errors.py — 错误类型与错误层
  • core/lvgl_ai/control/runtime.py — Runtime 与 input
  • core/lvgl_ai/web/webapp.py — HTTP 适配、常量、路由
  • core/lvgl_ai/web/live_session.py — LiveSession、live 状态机与 ticker
  • core/lvgl_ai/web/replay_model.py — 回放视图模型：帧、关键画面、时间线、diff、notes 与日志尾部一次读取
  • core/lvgl_ai/web/wire.py — raw 预览帧 magic、帧头、上限与页面心跳的单源
  • core/lvgl_ai/web/transport.py — raw 预览帧编码与 LiveFrameHub
  • core/web.py — 启动参数与默认地址
  • core/web.pyw — Windows 无控制台启动器（自动开浏览器、关闭页面即停服务）
  • core/README.md — 工具用法
  • user/scenarios/ — 场景脚本目录
  • .scratch/ai-tools/SPEC.md — 设计真源
