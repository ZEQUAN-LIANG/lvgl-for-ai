# LVGL 9.4 API 导航

本文件服务在 `user/app/*.c` 中实现 `void app_create(void)`。工具（运行时）已经调用 `lv_init`、按运行时尺寸创建 XRGB8888 display（默认 800×600）和标准虚拟 pointer / keypad / encoder indev，并驱动虚拟时间；用户不写 main，不注册 display / indev，也不在 app 里调用 `lv_timer_handler`。片段都放在 `app_create()` 或其调用的静态函数里。

> 版本：LVGL 9.4.0。符号和头文件路径按 `engine/lvgl/9.4` 核对；跨版本重命名见「与相邻版本差异」。

## 版本与源码路径

- 源码根：`engine/lvgl/9.4/`。
- 公共头文件根：`engine/lvgl/9.4/src/`；用户代码只写 `#include "lvgl.h"`，构建器负责 include 路径。
- 版本宏：`LVGL_VERSION_MAJOR` / `LVGL_VERSION_MINOR` / `LVGL_VERSION_PATCH` 为 9 / 4 / 0。
- 选择版本：`LVGL_VERIFY_LOOP_LVGL_VERSION=9.4`；`LVGL_VERIFY_LOOP_LVGL_SRC` 可覆盖源码路径。
- 构建产物：`build/lvgl_9_4/lvgl_engine.exe`。
- `lv_conf.h` 由工具持有：`LV_USE_OBJ_NAME=1`、`LV_USE_LOG=1`、`LV_USE_ASSERT=0`，字体只启用 Montserrat 14 / 16 / 20。

## 初始化 / display / indev

工具已经完成初始化。app 里只查询现成对象，不要再创建 display 或 indev。

- 当前屏幕：`lv_screen_active()`。
- display 查询：`lv_display_get_default()`、`lv_display_get_horizontal_resolution()`、`lv_display_get_vertical_resolution()`。
- indev 遍历：`lv_indev_get_next()`、`lv_indev_get_type()`、`lv_indev_get_group()`；当前被读取的 indev 用 `lv_indev_active()`。
- 类型：`lv_display_t`、`lv_indev_t`、`lv_obj_t`。

```c
/* 在 app_create() 内：读取工具建好的 display */
lv_display_t * disp = lv_display_get_default();
int32_t w = lv_display_get_horizontal_resolution(disp);
int32_t h = lv_display_get_vertical_resolution(disp);
lv_obj_t * screen = lv_screen_active();
printf("[app] display %ldx%ld\n", (long)w, (long)h);
```

## 对象与控件

通用对象用 `lv_obj_create()`；控件构造函数都以父对象为参数。常用控件：

- 文本：`lv_label_create()`、`lv_label_set_text()`、`lv_label_set_text_fmt()`、`lv_label_set_long_mode()`、`lv_label_set_recolor()`。
- 按钮：`lv_button_create()`。
- 数值：`lv_bar_create()`、`lv_bar_set_value()`、`lv_slider_create()`、`lv_slider_set_value()`。
- 开关 / 复选 / 下拉 / 文本输入：`lv_switch_create()`、`lv_checkbox_create()`、`lv_dropdown_create()`、`lv_textarea_create()`。
- 列表 / 图片：`lv_list_create()`、`lv_list_add_button()`、`lv_image_create()`。

通用对象操作：`lv_obj_set_pos()`、`lv_obj_set_size()`、`lv_obj_set_width()`、`lv_obj_center()`、`lv_obj_align()`、`lv_obj_add_flag()`、`lv_obj_remove_flag()`、`lv_obj_update_layout()`、`lv_obj_delete()`。对象名用 `lv_obj_set_name()`、`lv_obj_get_name()`，受 `LV_USE_OBJ_NAME=1` 控制；名字会进入 `timeline.ndjson` 的 `hit`。

```c
/* 在 app_create() 内：按钮 + 文本 */
lv_obj_t * screen = lv_screen_active();
lv_obj_t * button = lv_button_create(screen);
lv_obj_set_pos(button, 32, 300);
lv_obj_set_size(button, 160, 48);
lv_obj_set_name(button, "main_button");

lv_obj_t * label = lv_label_create(button);
lv_label_set_text(label, "Click");
lv_obj_center(label);
lv_obj_remove_flag(label, LV_OBJ_FLAG_CLICKABLE);
```

```c
/* 在 app_create() 内：隐藏、恢复、删除 */
lv_obj_add_flag(panel, LV_OBJ_FLAG_HIDDEN);
lv_obj_remove_flag(panel, LV_OBJ_FLAG_HIDDEN);
lv_obj_delete(panel); /* 删除对象及其子对象 */
```

## 样式

两种方式：

- 直接设到对象：`lv_obj_set_style_bg_color()`、`lv_obj_set_style_bg_opa()`、`lv_obj_set_style_text_color()`、`lv_obj_set_style_text_font()`、`lv_obj_set_style_border_width()`、`lv_obj_set_style_border_color()`、`lv_obj_set_style_radius()`、`lv_obj_set_style_pad_all()`、`lv_obj_set_style_pad_row()`、`lv_obj_set_style_pad_column()`、`lv_obj_set_style_opa()`。最后一个参数是 selector：`0` 表示 `LV_PART_MAIN` / 默认状态，也可组合 `LV_PART_*` 与 `LV_STATE_*`。
- 可复用样式：`lv_style_t` + `lv_style_init()`、`lv_style_set_*()`，再用 `lv_obj_add_style()` 挂到对象；`lv_obj_remove_style_all()` 可先清掉主题默认样式。

颜色用 `lv_color_hex()`、`lv_color_white()`、`lv_color_black()`、`lv_palette_main()`；透明度常量用 `LV_OPA_COVER` / `LV_OPA_TRANSP`。

```c
/* 在 app_create() 内：直接样式 */
lv_obj_t * card = lv_obj_create(screen);
lv_obj_remove_style_all(card);
lv_obj_set_style_bg_color(card, lv_color_hex(0x1E293B), 0);
lv_obj_set_style_bg_opa(card, LV_OPA_COVER, 0);
lv_obj_set_style_radius(card, 12, 0);
lv_obj_set_style_pad_all(card, 16, 0);
lv_obj_set_style_text_color(card, lv_color_white(), 0);
```

```c
/* 在 app_create() 内：可复用样式，style 对象需比控件活得久 */
static lv_style_t card_style;
lv_style_init(&card_style);
lv_style_set_bg_color(&card_style, lv_color_hex(0x0F172A));
lv_style_set_bg_opa(&card_style, LV_OPA_COVER);
lv_style_set_radius(&card_style, 12);
lv_obj_add_style(card, &card_style, 0);
```

## 布局

- Flex：`lv_obj_set_flex_flow()`、`lv_obj_set_flex_align()`；间距用 `lv_obj_set_style_pad_row()` / `lv_obj_set_style_pad_column()` 或 `lv_obj_set_style_pad_gap()`；子项占比用 `lv_obj_set_style_flex_grow()`。
- Grid：容器上 `lv_obj_set_grid_dsc_array()`，子项上 `lv_obj_set_grid_cell()`；列/行描述数组末项必须是 `LV_GRID_TEMPLATE_LAST`。
- 常见尺寸：`lv_pct()`、`LV_SIZE_CONTENT`；布局改动后用 `lv_obj_update_layout()` 可立即更新布局。
- 以上 API 需要 `LV_USE_FLEX` / `LV_USE_GRID`，工具已打开。

```c
/* 在 app_create() 内：横向排列，两端对齐 */
lv_obj_set_flex_flow(row, LV_FLEX_FLOW_ROW);
lv_obj_set_flex_align(row, LV_FLEX_ALIGN_SPACE_BETWEEN,
                      LV_FLEX_ALIGN_CENTER, LV_FLEX_ALIGN_CENTER);
lv_obj_set_style_pad_column(row, 12, 0);
lv_obj_set_style_flex_grow(grow_item, 1, 0);
```

```c
/* 文件作用域或 static：网格描述数组必须长期有效 */
static int32_t cols[] = {LV_GRID_FR(1), LV_GRID_FR(2), LV_GRID_TEMPLATE_LAST};
static int32_t rows[] = {LV_GRID_CONTENT, LV_GRID_FR(1), LV_GRID_TEMPLATE_LAST};
/* 在 app_create() 内 */
lv_obj_set_grid_dsc_array(grid, cols, rows);
lv_obj_set_grid_cell(cell, LV_GRID_ALIGN_STRETCH, 1, 1,
                     LV_GRID_ALIGN_STRETCH, 0, 1);
```

## 事件

- 注册：`lv_obj_add_event_cb()`；注销：`lv_obj_remove_event_cb()`。
- 事件函数里取事件码：`lv_event_get_code()`；取目标对象：`lv_event_get_target_obj()`；取当前目标：`lv_event_get_current_target_obj()`；取注册时的 user_data：`lv_event_get_user_data()`。
- 键盘 / encoder 事件用 `LV_EVENT_KEY`，键值用 `lv_event_get_key()`。
- 常用事件码：`LV_EVENT_CLICKED`、`LV_EVENT_VALUE_CHANGED`、`LV_EVENT_PRESSED`、`LV_EVENT_FOCUSED`、`LV_EVENT_KEY`、`LV_EVENT_READY`、`LV_EVENT_CANCEL`、`LV_EVENT_DELETE`。
- 主动发事件：`lv_event_send()`。

```c
/* 在 app_create() 内注册；事件函数可在文件上方 */
static void on_clicked(lv_event_t * e)
{
    lv_obj_t * target = lv_event_get_target_obj(e);
    const char * name = lv_obj_get_name(target);
    printf("[app] clicked %s\n", name != NULL ? name : "object");
}
/* app_create() 内 */
lv_obj_add_event_cb(button, on_clicked, LV_EVENT_CLICKED, NULL);
```

```c
/* 在 app_create() 内：keypad / encoder 的按键事件 */
static void on_key(lv_event_t * e)
{
    uint32_t key = lv_event_get_key(e);
    if(key == LV_KEY_ENTER) printf("[app] enter\n");
    if(key == LV_KEY_NEXT || key == LV_KEY_RIGHT) printf("[app] next\n");
}
lv_obj_add_event_cb(button, on_key, LV_EVENT_KEY, NULL);
```

## 定时器与动画

- 定时器：`lv_timer_create()`、`lv_timer_set_period()`、`lv_timer_set_repeat_count()`、`lv_timer_pause()`、`lv_timer_resume()`、`lv_timer_delete()`；定时器函数里用 `lv_timer_get_user_data()`。
- 动画：`lv_anim_t`、`lv_anim_init()`、`lv_anim_set_var()`、`lv_anim_set_values()`、`lv_anim_set_duration()`、`lv_anim_set_exec_cb()`、`lv_anim_set_path_cb()`、`lv_anim_start()`、`lv_anim_delete()`；9.4 也提供 `lv_anim_pause()` / `lv_anim_resume()`；路径函数如 `lv_anim_path_ease_in_out()`、`lv_anim_path_linear()`。
- 时间来自虚拟时间：只有 `tick <ms>` / `wait <ms>` 推进 `lv_timer_handler` 后定时器和动画才会前进；可用 `lv_tick_get()`、`lv_tick_elaps()` 读时间。

```c
/* 在 app_create() 内：每 500 ms 执行一次，共 3 次 */
static void on_tick(lv_timer_t * timer)
{
    int32_t * count = lv_timer_get_user_data(timer);
    (*count)++;
    printf("[app] tick %d\n", (int)*count);
}
static int32_t count;
lv_timer_t * timer = lv_timer_create(on_tick, 500, &count);
lv_timer_set_repeat_count(timer, 3); /* -1 表示一直重复 */
```

```c
/* 在 app_create() 内：300 ms 淡入 */
static void set_opa(void * var, int32_t value)
{
    lv_obj_set_style_opa((lv_obj_t *)var, (lv_opa_t)value, 0);
}
lv_anim_t anim;
lv_anim_init(&anim);
lv_anim_set_var(&anim, card);
lv_anim_set_values(&anim, LV_OPA_TRANSP, LV_OPA_COVER);
lv_anim_set_duration(&anim, 300);
lv_anim_set_exec_cb(&anim, set_opa);
lv_anim_set_path_cb(&anim, lv_anim_path_ease_in_out);
lv_anim_start(&anim);
```

## 字体与图片

- 已编译字体：`lv_font_montserrat_14`、`lv_font_montserrat_16`、`lv_font_montserrat_20`；用 `lv_obj_set_style_text_font(obj, &lv_font_montserrat_20, 0)` 设置。自定义字体需要把 C 数组放进 `user/app/` 并自行声明。
- 符号字符：`lv_label_set_text(label, LV_SYMBOL_OK " OK")`；`LV_SYMBOL_CLOSE`、`LV_SYMBOL_SETTINGS` 等由 `font/lv_symbol_def.h` 提供。
- 图片描述符类型是 `lv_image_dsc_t`；资源以 C 数组或文件路径放在 `user/app/`（通常与使用它的代码同目录）。
- 图片控件：`lv_image_create()`、`lv_image_set_src()`、`lv_image_set_scale()`（256 = 1×）、`lv_image_set_rotation()`（0.1° 单位）。

```c
/* 在 app_create() 内：字体与符号 */
lv_label_set_text(label, LV_SYMBOL_OK " Ready");
lv_obj_set_style_text_font(label, &lv_font_montserrat_20, 0);
lv_label_set_long_mode(label, LV_LABEL_LONG_MODE_WRAP);
```

```c
/* apps 中定义：extern const lv_image_dsc_t my_logo; */
lv_obj_t * image = lv_image_create(screen);
lv_image_set_src(image, &my_logo);
lv_image_set_scale(image, 256); /* 1x */
lv_image_set_rotation(image, 0);
```

## keypad / encoder / group

工具只创建标准 keypad / encoder indev，不创建焦点组；组属于 `apps`。把组挂到 indev 后，工具发送的按键和 encoder 步进才会落到控件上。

- 组：`lv_group_create()`、`lv_group_add_obj()`、`lv_group_remove_obj()`、`lv_group_focus_obj()`、`lv_group_focus_next()`、`lv_group_focus_prev()`、`lv_group_get_focused()`、`lv_group_set_editing()`、`lv_group_get_editing()`、`lv_group_set_wrap()`、`lv_group_delete()`。
- indev：`lv_indev_get_next()`、`lv_indev_get_type()`、`lv_indev_set_group()`、`lv_indev_wait_release()`；类型常量 `LV_INDEV_TYPE_KEYPAD`、`LV_INDEV_TYPE_ENCODER`、`LV_INDEV_TYPE_POINTER`。
- 工具支持的键名：`UP`、`DOWN`、`RIGHT`、`LEFT`、`ESC`、`DEL`、`BACKSPACE`、`ENTER`、`NEXT`、`PREV`、`HOME`、`END`（不含 `INSERT`）。encoder 正 diff 为焦点前进。

```c
/* 在 app_create() 内：建组并挂到工具的 keypad / encoder */
static lv_group_t * group;
group = lv_group_create();
lv_group_add_obj(group, panel);
lv_group_add_obj(group, button);
lv_group_focus_obj(button);
for(lv_indev_t * indev = lv_indev_get_next(NULL); indev != NULL;
    indev = lv_indev_get_next(indev)) {
    lv_indev_type_t type = lv_indev_get_type(indev);
    if(type == LV_INDEV_TYPE_KEYPAD || type == LV_INDEV_TYPE_ENCODER) {
        lv_indev_set_group(indev, group);
    }
}
```

## 日志与断言

- 精确状态（checked / value / text / focus / scroll）的唯一通道是 `printf` 到 stdout；工具把 stdout / stderr 收进 `engine.log`。没有 tree、inspect、set、param，也不要在 app 里假装有查询入口。
- `LV_LOG_USER()`、`LV_LOG_WARN()`、`LV_LOG_ERROR()` 会输出；`LV_LOG_INFO()` / `LV_LOG_TRACE()` 被 `LV_LOG_LEVEL_WARN` 过滤。`lv_log_register_print_cb()` 可换日志输出函数；工具已设置 `LV_LOG_PRINTF=1`，日志直接进 stdout / engine.log，通常不需要再改。
- 9.x 工具配置 `LV_USE_ASSERT=0`，`LV_ASSERT_MSG()` 展开为空；不要用断言表达验收条件，用显式分支和 `printf`。

```c
/* 在 app_create() 内：把关键状态写进 engine.log */
printf("[app] slider=%d checked=%d\n",
       (int)lv_slider_get_value(slider),
       (int)lv_obj_has_state(check, LV_STATE_CHECKED));
LV_LOG_USER("card ready");
```

## 与相邻版本差异

- 本导航覆盖范围内，9.4 对 9.6 的关键差异：9.6 才新增 `lv_obj_set_clickable()`；9.4 用 `lv_obj_remove_flag(obj, LV_OBJ_FLAG_CLICKABLE)`。9.6 把头文件重新分目录（`misc/*` → `core/*`、`draw/*`、`logging/*`、`debugging/*`，`widgets/<name>/` → `widgets/*`）；9.4 仍是 `src/misc/*` 与 `src/widgets/<name>/*`。
- 本导航覆盖范围内，9.4 对 9.5 的关键差异：9.5 新增 `lv_group_set_user_data()` / `lv_group_get_user_data()`、`lv_obj_set_radio_button()`、`lv_obj_is_radio_button()`、`lv_dropdown_set_text_static()`、`lv_textarea_set_accepted_chars_static()`、模糊与投影样式；9.4 没有这些，写 9.4 时不要用。
- 9.4 对 9.1：对象名 API `lv_obj_set_name()` / `lv_obj_get_name()` 从 9.2 起才有；`LV_USE_OBJ_NAME` 在 9.1 不存在。9.1 的 `hit` 永远为空，`hit_class` 是短名 `btn` / `obj` / `label` / `image`；9.4 的 `hit_class` 是 `lv_button` / `lv_obj` / `lv_label` / `lv_image`。
- 9.1 没有 `lv_label_set_recolor()`；9.4 才有。9.1 的 `LV_LABEL_LONG_WRAP` 在 9.4 改名为 `LV_LABEL_LONG_MODE_WRAP`。
- 9.1 还保留旧 `lv_anim_set_time()` 内联别名；9.4 的规范名是 `lv_anim_set_duration()`，旧名只作兼容宏。9.4 新增 `lv_anim_pause()` / `lv_anim_resume()`，9.1 没有。
- `hit` 只在对象调用过 `lv_obj_set_name()` 后才有值；没有命名时 `hit` 为空字符串，`hit_class` 仍可用。
