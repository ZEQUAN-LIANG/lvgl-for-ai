# LVGL 8.4 API 导航

本文件服务在 `user/app/*.c` 中实现 `void app_create(void)`。工具（运行时）已经调用 `lv_init`，用 8.x 的 display / indev 驱动函数按运行时尺寸创建 XRGB8888 display（默认 800×600）和标准虚拟 pointer / keypad / encoder indev，并驱动虚拟时间；用户不写 main，不注册 display / indev，也不在 app 里调用 `lv_timer_handler`。片段都放在 `app_create()` 或其调用的静态函数里。

> 版本：LVGL 8.4.0。符号和头文件路径按 `engine/lvgl/8.4` 核对；跨版本重命名见「与相邻版本差异」。

## 版本与源码路径

- 源码根：`engine/lvgl/8.4/`。
- 公共头文件根：`engine/lvgl/8.4/src/`；根 `engine/lvgl/8.4/lvgl.h` 汇总声明。用户代码只写 `#include "lvgl.h"`。
- 版本宏：`LVGL_VERSION_MAJOR` / `LVGL_VERSION_MINOR` / `LVGL_VERSION_PATCH` 为 8 / 4 / 0；8.x 把版本宏放在根 `lvgl.h`，没有 `lv_version.h`。
- 选择版本：`LVGL_VERIFY_LOOP_LVGL_VERSION=8.4`；`LVGL_VERIFY_LOOP_LVGL_SRC` 可覆盖源码路径。
- 构建产物：`build/lvgl_8_4/lvgl_engine.exe`。
- `lv_conf.h` 由工具持有：`LV_COLOR_DEPTH=32`、`LV_USE_LOG=1`、`LV_USE_ASSERT_NULL=0` 等单项断言关闭，字体只启用 Montserrat 14 / 16 / 20。

## 初始化 / display / indev

8.x 用旧的驱动结构体注册 display / indev。工具层已经在 `adapter_8x.c` 里做完，用户 app 不要重复调用。

```c
/* 工具层参考：不要在 app_create() 里复制这段；width/height 来自运行时参数（默认 800×600） */
lv_disp_draw_buf_t draw_buf;
lv_disp_draw_buf_init(&draw_buf, buf, NULL, width * height);

lv_disp_drv_t disp_drv;
lv_disp_drv_init(&disp_drv);
disp_drv.hor_res = width;
disp_drv.ver_res = height;
disp_drv.flush_cb = my_flush_cb;
disp_drv.draw_buf = &draw_buf;
lv_disp_drv_register(&disp_drv);

lv_indev_drv_t indev_drv;
lv_indev_drv_init(&indev_drv);
indev_drv.type = LV_INDEV_TYPE_POINTER;
indev_drv.read_cb = my_read_cb;
lv_indev_drv_register(&indev_drv);
```

app 里只查询现成对象：

- 当前屏幕：`lv_scr_act()`（`lvgl_compat.h` 还提供 `lv_screen_active()` shim）。
- display 查询：`lv_disp_get_default()`、`lv_disp_get_scr_act()`、`lv_disp_get_hor_res()`、`lv_disp_get_ver_res()`。
- indev 遍历：`lv_indev_get_next()`、`lv_indev_get_type()`、`lv_indev_set_group()`；当前被读取的 indev 用 `lv_indev_get_act()`。
- 类型：`lv_disp_t`、`lv_indev_t`、`lv_obj_t`。

```c
/* 在 app_create() 内：app.h 已包含 lvgl_compat.h，提供 9.x 同名 shim */
lv_obj_t * screen = lv_screen_active(); /* → lv_scr_act() */
lv_disp_t * disp = lv_disp_get_default();
printf("[app] display %dx%d\n",
       (int)lv_disp_get_hor_res(disp), (int)lv_disp_get_ver_res(disp));
```

## 对象与控件

通用对象用 `lv_obj_create()`；8.x 控件构造函数使用短名：

- 文本：`lv_label_create()`、`lv_label_set_text()`、`lv_label_set_text_fmt()`、`lv_label_set_long_mode()`。
- 按钮：`lv_btn_create()`。
- 数值：`lv_bar_create()`、`lv_bar_set_value()`、`lv_slider_create()`、`lv_slider_set_value()`。
- 开关 / 复选 / 下拉 / 文本输入：`lv_switch_create()`、`lv_checkbox_create()`、`lv_dropdown_create()`、`lv_textarea_create()`。
- 列表 / 图片：`lv_list_create()`、`lv_list_add_btn()`、`lv_img_create()`。

通用对象操作：`lv_obj_set_pos()`、`lv_obj_set_size()`、`lv_obj_set_width()`、`lv_obj_center()`、`lv_obj_align()`、`lv_obj_add_flag()`、`lv_obj_clear_flag()`、`lv_obj_add_state()`、`lv_obj_clear_state()`、`lv_obj_update_layout()`、`lv_obj_del()`。遍历子对象用 `lv_obj_get_child_cnt()`。

本版本没有对象名 API：没有 `LV_USE_OBJ_NAME`，也没有 `lv_obj_set_name()` / `lv_obj_get_name()`。`timeline.ndjson` 的 `hit` 永远为空字符串；`hit_class` 来自 adapter 的控件类映射，值为 `lv_btn`、`lv_obj`、`lv_label`、`lv_img`，未知类回退到最近的已知基类。

```c
/* 在 app_create() 内：按钮 + 文本 */
lv_obj_t * screen = lv_scr_act();
lv_obj_t * button = lv_btn_create(screen);
lv_obj_set_pos(button, 32, 300);
lv_obj_set_size(button, 160, 48);

lv_obj_t * label = lv_label_create(button);
lv_label_set_text(label, "Click");
lv_obj_center(label);
lv_obj_clear_flag(label, LV_OBJ_FLAG_CLICKABLE);
```

```c
/* 在 app_create() 内：隐藏、恢复、删除 */
lv_obj_add_flag(panel, LV_OBJ_FLAG_HIDDEN);
lv_obj_clear_flag(panel, LV_OBJ_FLAG_HIDDEN);
lv_obj_del(panel);
```

## 样式

- 直接设到对象：`lv_obj_set_style_bg_color()`、`lv_obj_set_style_bg_opa()`、`lv_obj_set_style_text_color()`、`lv_obj_set_style_text_font()`、`lv_obj_set_style_border_width()`、`lv_obj_set_style_border_color()`、`lv_obj_set_style_radius()`、`lv_obj_set_style_pad_all()`、`lv_obj_set_style_pad_row()`、`lv_obj_set_style_pad_column()`、`lv_obj_set_style_opa()`。
- 可复用样式：`lv_style_t` + `lv_style_init()`、`lv_style_set_*()`，再用 `lv_obj_add_style()` 挂到对象；`lv_obj_remove_style_all()` 可先清掉主题默认样式。
- 颜色用 `lv_color_hex()`、`lv_color_white()`、`lv_color_black()`、`lv_palette_main()`；透明度常量用 `LV_OPA_COVER` / `LV_OPA_TRANSP`。

```c
/* 在 app_create() 内：直接样式 */
lv_obj_t * card = lv_obj_create(screen);
lv_obj_remove_style_all(card);
lv_obj_set_style_bg_color(card, lv_color_hex(0x1E293B), 0);
lv_obj_set_style_bg_opa(card, LV_OPA_COVER, 0);
lv_obj_set_style_radius(card, 12, 0);
lv_obj_set_style_pad_all(card, 16, 0);
lv_obj_set_style_text_color(card, lv_color_white(), 0);
```

```c
/* 在 app_create() 内：可复用样式，style 对象需比控件活得久 */
static lv_style_t card_style;
lv_style_init(&card_style);
lv_style_set_bg_color(&card_style, lv_color_hex(0x0F172A));
lv_style_set_bg_opa(&card_style, LV_OPA_COVER);
lv_style_set_radius(&card_style, 12);
lv_obj_add_style(card, &card_style, 0);
```

## 布局

- Flex：`lv_obj_set_flex_flow()`、`lv_obj_set_flex_align()`；间距用 `lv_obj_set_style_pad_row()` / `lv_obj_set_style_pad_column()` 或 `lv_obj_set_style_pad_gap()`；子项占比用 `lv_obj_set_style_flex_grow()`。
- Grid：容器上 `lv_obj_set_grid_dsc_array()`，子项上 `lv_obj_set_grid_cell()`；列/行描述数组末项必须是 `LV_GRID_TEMPLATE_LAST`。
- 常见尺寸：`lv_pct()`、`LV_SIZE_CONTENT`；布局改动后用 `lv_obj_update_layout()` 可立即更新布局。
- 8.x 的 flex / grid 放在 `src/extra/layouts/`，需要 `LV_USE_FLEX` / `LV_USE_GRID`，工具已打开。

```c
/* 在 app_create() 内：横向排列，两端对齐 */
lv_obj_set_flex_flow(row, LV_FLEX_FLOW_ROW);
lv_obj_set_flex_align(row, LV_FLEX_ALIGN_SPACE_BETWEEN,
                      LV_FLEX_ALIGN_CENTER, LV_FLEX_ALIGN_CENTER);
lv_obj_set_style_pad_column(row, 12, 0);
lv_obj_set_style_flex_grow(grow_item, 1, 0);
```

```c
/* 文件作用域或 static：网格描述数组必须长期有效 */
static int32_t cols[] = {LV_GRID_FR(1), LV_GRID_FR(2), LV_GRID_TEMPLATE_LAST};
static int32_t rows[] = {LV_GRID_CONTENT, LV_GRID_FR(1), LV_GRID_TEMPLATE_LAST};
/* 在 app_create() 内 */
lv_obj_set_grid_dsc_array(grid, cols, rows);
lv_obj_set_grid_cell(cell, LV_GRID_ALIGN_STRETCH, 1, 1,
                     LV_GRID_ALIGN_STRETCH, 0, 1);
```

## 事件

- 注册：`lv_obj_add_event_cb()`；注销：`lv_obj_remove_event_cb()`。
- 事件函数里取事件码：`lv_event_get_code()`；取目标对象：`lv_event_get_target()`；取当前目标：`lv_event_get_current_target()`；取注册时的 user_data：`lv_event_get_user_data()`。
- 键盘 / encoder 事件用 `LV_EVENT_KEY`，键值用 `lv_event_get_key()`。
- 常用事件码：`LV_EVENT_CLICKED`、`LV_EVENT_VALUE_CHANGED`、`LV_EVENT_PRESSED`、`LV_EVENT_FOCUSED`、`LV_EVENT_KEY`、`LV_EVENT_READY`、`LV_EVENT_CANCEL`、`LV_EVENT_DELETE`。

```c
/* 在 app_create() 内注册；事件函数可在文件上方 */
static void on_clicked(lv_event_t * e)
{
    lv_obj_t * target = lv_event_get_target(e);
    (void)target;
    printf("[app] clicked\n"); /* 8.x 无对象名，hit 为空 */
}
/* app_create() 内 */
lv_obj_add_event_cb(button, on_clicked, LV_EVENT_CLICKED, NULL);
```

```c
/* 在 app_create() 内：keypad / encoder 的按键事件 */
static void on_key(lv_event_t * e)
{
    uint32_t key = lv_event_get_key(e);
    if(key == LV_KEY_ENTER) printf("[app] enter\n");
    if(key == LV_KEY_NEXT || key == LV_KEY_RIGHT) printf("[app] next\n");
}
lv_obj_add_event_cb(button, on_key, LV_EVENT_KEY, NULL);
```

## 定时器与动画

- 定时器：`lv_timer_create()`、`lv_timer_set_period()`、`lv_timer_set_repeat_count()`、`lv_timer_pause()`、`lv_timer_resume()`、`lv_timer_del()`；定时器函数里用静态变量保存状态。
- 动画：`lv_anim_t`、`lv_anim_init()`、`lv_anim_set_var()`、`lv_anim_set_values()`、`lv_anim_set_time()`、`lv_anim_set_exec_cb()`、`lv_anim_set_path_cb()`、`lv_anim_start()`、`lv_anim_del()`；路径函数如 `lv_anim_path_ease_in_out()`、`lv_anim_path_linear()`。
- 时间来自虚拟时间：只有 `tick <ms>` / `wait <ms>` 推进 `lv_timer_handler` 后定时器和动画才会前进；可用 `lv_tick_get()`、`lv_tick_elaps()` 读时间。

```c
/* 在 app_create() 内：每 500 ms 执行一次，共 3 次 */
static int32_t tick_count;
static void on_tick(lv_timer_t * timer)
{
    (void)timer;
    tick_count++;
    printf("[app] tick %d\n", (int)tick_count);
}
lv_timer_t * timer = lv_timer_create(on_tick, 500, NULL);
lv_timer_set_repeat_count(timer, 3);
```

```c
/* 在 app_create() 内：300 ms 淡入 */
static void set_opa(void * var, int32_t value)
{
    lv_obj_set_style_opa((lv_obj_t *)var, (lv_opa_t)value, 0);
}
lv_anim_t anim;
lv_anim_init(&anim);
lv_anim_set_var(&anim, card);
lv_anim_set_values(&anim, LV_OPA_TRANSP, LV_OPA_COVER);
lv_anim_set_time(&anim, 300);
lv_anim_set_exec_cb(&anim, set_opa);
lv_anim_set_path_cb(&anim, lv_anim_path_ease_in_out);
lv_anim_start(&anim);
```

## 字体与图片

- 已编译字体：`lv_font_montserrat_14`、`lv_font_montserrat_16`、`lv_font_montserrat_20`；用 `lv_obj_set_style_text_font(obj, &lv_font_montserrat_20, 0)` 设置。
- 符号字符：`lv_label_set_text(label, LV_SYMBOL_OK " OK")`；`LV_SYMBOL_CLOSE`、`LV_SYMBOL_SETTINGS` 等由 `font/lv_symbol_def.h` 提供。
- 文本换行用 `LV_LABEL_LONG_WRAP`。
- 图片描述符类型是 `lv_img_dsc_t`；资源以 C 数组或文件路径放在 `user/app/`（通常与使用它的代码同目录）。
- 图片控件：`lv_img_create()`、`lv_img_set_src()`、`lv_img_set_zoom()`（256 = 1×）、`lv_img_set_angle()`（0.1° 单位）。

```c
/* 在 app_create() 内：字体、符号与换行 */
lv_label_set_text(label, LV_SYMBOL_OK " Ready");
lv_obj_set_style_text_font(label, &lv_font_montserrat_20, 0);
lv_label_set_long_mode(label, LV_LABEL_LONG_WRAP);
```

```c
/* apps 中定义：extern const lv_img_dsc_t my_logo; */
lv_obj_t * image = lv_img_create(screen);
lv_img_set_src(image, &my_logo);
lv_img_set_zoom(image, 256); /* 1x */
lv_img_set_angle(image, 0);
```

## keypad / encoder / group

工具只创建标准 keypad / encoder indev，不创建焦点组；组属于 `apps`。把组挂到 indev 后，工具发送的按键和 encoder 步进才会落到控件上。

- 组：`lv_group_create()`、`lv_group_add_obj()`、`lv_group_remove_obj()`、`lv_group_focus_obj()`、`lv_group_focus_next()`、`lv_group_focus_prev()`、`lv_group_get_focused()`、`lv_group_set_editing()`、`lv_group_get_editing()`、`lv_group_set_wrap()`、`lv_group_del()`。
- indev：`lv_indev_get_next()`、`lv_indev_get_type()`、`lv_indev_set_group()`、`lv_indev_wait_release()`；类型常量 `LV_INDEV_TYPE_KEYPAD`、`LV_INDEV_TYPE_ENCODER`、`LV_INDEV_TYPE_POINTER`。
- 工具支持的键名：`UP`、`DOWN`、`RIGHT`、`LEFT`、`ESC`、`DEL`、`BACKSPACE`、`ENTER`、`NEXT`、`PREV`、`HOME`、`END`（不含 `INSERT`）。encoder 正 diff 为焦点前进。

```c
/* 在 app_create() 内：建组并挂到工具的 keypad / encoder */
static lv_group_t * group;
group = lv_group_create();
lv_group_add_obj(group, panel);
lv_group_add_obj(group, button);
lv_group_focus_obj(button);
for(lv_indev_t * indev = lv_indev_get_next(NULL); indev != NULL;
    indev = lv_indev_get_next(indev)) {
    lv_indev_type_t type = lv_indev_get_type(indev);
    if(type == LV_INDEV_TYPE_KEYPAD || type == LV_INDEV_TYPE_ENCODER) {
        lv_indev_set_group(indev, group);
    }
}
```

## 日志与断言

- 精确状态（checked / value / text / focus / scroll）的唯一通道是 `printf` 到 stdout；工具把 stdout / stderr 收进 `engine.log`。没有 tree、inspect、set、param，也不要在 app 里假装有查询入口。
- `LV_LOG_USER()`、`LV_LOG_WARN()`、`LV_LOG_ERROR()` 会输出；`LV_LOG_INFO()` / `LV_LOG_TRACE()` 被 `LV_LOG_LEVEL_WARN` 过滤。`lv_log_register_print_cb()` 可换日志输出函数；工具已设置 `LV_LOG_PRINTF=1`，日志直接进 stdout / engine.log，通常不需要再改。
- `LV_ASSERT_MSG()` 仍会进入断言处理器，但工具配置关闭了 NULL / MALLOC 等单项断言。不要用断言表达验收条件，用显式分支和 `printf`。

```c
/* 在 app_create() 内：把关键状态写进 engine.log */
printf("[app] slider=%d checked=%d\n",
       (int)lv_slider_get_value(slider),
       (int)lv_obj_has_state(check, LV_STATE_CHECKED));
LV_LOG_USER("card ready");
```

## 与相邻版本差异

- 8.4 对 8.3：本导航覆盖的 API 相同；8.4 只多出 `lv_calendar_header_dropdown_set_year_list()`，8.3 没有。写 8.3 兼容代码时不要用这个函数。
- 8.4 对 9.x：对象名不可用（8.x 没有 `LV_USE_OBJ_NAME`，也没有 `lv_obj_set_name()`）；控件短名不同：`lv_btn_create()` 对 9.x 的 `lv_button_create()`，`lv_img_create()` 对 `lv_image_create()`；对象删除用 `lv_obj_del()`（9.x 是 `lv_obj_delete()`），定时器用 `lv_timer_del()`（9.x 是 `lv_timer_delete()`），动画用 `lv_anim_del()`（9.x 是 `lv_anim_delete()`），组用 `lv_group_del()`（9.x 是 `lv_group_delete()`）。
- 8.x 事件取值用 `lv_event_get_target()` / `lv_event_get_current_target()`；9.x 用 `lv_event_get_target_obj()` / `lv_event_get_current_target_obj()`。
- 8.x 的 display / indev 用 `lv_disp_drv_t` / `lv_indev_drv_t` 与 `lv_disp_drv_register()` / `lv_indev_drv_register()`；9.x 用 `lv_display_t` / `lv_indev_t` 与 `lv_display_*` / `lv_indev_*`。
- 8.x 图片类型是 `lv_img_dsc_t`；9.x 是 `lv_image_dsc_t`。8.x 的 `lv_obj_get_child_cnt()` 在 9.x 改名为 `lv_obj_get_child_count()`。
- `hit` 在 8.x 永远为空；`hit_class` 为 `lv_btn` / `lv_obj` / `lv_label` / `lv_img`。
